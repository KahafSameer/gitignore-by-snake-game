# .gitignore Practice: Snake Game

A Python **Snake game** built with `turtle`, used to practice writing a `.gitignore`.

## The game (`snakgame.py`)

- Black background, white snake head, red food, a border around the play area
- Start screen with instructions
- Current score and high score (saved to `highscore.txt`)

Built with the Python standard library only (`turtle`, `time`, `random`, `os`).

## Run

```bash
git clone https://github.com/KahafSameer/gitignore-by-snake-game.git
cd gitignore-by-snake-game
python snakgame.py
```

## The .gitignore exercise

`.gitignore` ignores `*.css`, `app.py` and `templates/`, so files matching those patterns are never committed.
